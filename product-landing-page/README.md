# PulseFit - Responsive Product Landing Page

This is my Week 02 Minor Project for Web Development. It is a responsive
landing page for a fictional smart fitness watch called **PulseFit**.

## Project Structure

```
product-landing-page/
│
├── index.html          -> main HTML file
├── css/
│   └── style.css        -> all styling (Flexbox + Grid + Media Queries)
├── js/
│   └── script.js         -> mobile menu toggle + order button
├── images/
│   ├── watch.svg
│   └── benefits.svg
└── README.md
```

## Sections Included

1. Navbar - logo, nav links, mobile hamburger menu
2. Hero section - product title, description and CTA button
3. Features section - 5 feature cards laid out with CSS Grid
4. Benefits section - text + image using Flexbox
5. Testimonials - 3 customer reviews in a grid
6. Pricing / CTA - price and order button
7. Footer - contact info, social links, copyright

## Technologies Used

- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript
- Fully responsive (mobile, tablet, desktop breakpoints)

## How to Run

Just open `index.html` in any browser. No build tools or dependencies needed.

## What I Learned

- Building layouts with Flexbox and Grid together
- Writing media queries for different screen sizes
- Toggling a mobile navigation menu with plain JavaScript
